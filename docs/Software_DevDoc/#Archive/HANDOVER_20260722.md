## ⚠️ Zjištěný problém prostředí (ne kódu)
`esphome compile` úspěšně zkompiluje a slinkuje firmware (RAM 10.9 %, Flash 52.6 %,
`firmware.elf` OK) — moje lambda logika (wait_until/delay/timeout s clampem) je tedy
syntakticky v pořádku. Selhává až poslední krok (`.elf` → `.bin`) kvůli
`ModuleNotFoundError: No module named 'esptool'` — PlatformIO má **vlastní** Python
venv (`~/.platformio/penv`), oddělený od `firmware/.venv`, a esptool tam chybí (v
`firmware/.venv` nainstalovaný je, verze 5.1.0). Nezasahoval jsem do systémového
prostředí sám — potřeba `pip install esptool` do `~/.platformio/penv`, nebo
ekvivalentní oprava PlatformIO instalace, než půjde reálně flashnout.
